# Appearance

This category documents the renderer's global theme and appearance surfaces.
It is separate from the per-element appearance editor because global mode,
contrast and motion preferences affect every rendered page.

| Article | Covers |
| --- | --- |
| [ThemePageControl](theme-page.md) | Light, dark, system and high-contrast selection, persistence, keyboard access and reduced-motion behaviour. |

There is no HTTP API in this category. Theme state is renderer configuration
persisted through the existing `theme` preference path.
