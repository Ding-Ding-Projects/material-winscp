# Roadmap

> Partly generated by `node tools/handoff.js`. The roadmap also lives as GitHub
> issues, which are the authoritative tracker — this file is the readable
> summary of the same thing.

The goal is stated in [`docs/porting-mandate.md`](docs/porting-mandate.md) and is
not negotiable: **port 100% of WinSCP, however many lines it takes.** Scale is
not a reason to narrow scope.

**Currently 55.3% of 209,889 logic lines.**

## Done

- Electron application with a Material Design 3 interface, booting and usable
- Squirrel installer: built, installed and launched from the installed location
- Silent background updates, Chrome-style, with no prompt at any point
- Six protocol backends: SFTP, SCP, FTP/FTPS, WebDAV, S3 and the local filesystem
- Transfer queue, synchronizer, file masks, recursive search, session management
- All 301 WinSCP actions registered and reachable; 48 dialogs built
- End-to-end suites against real in-process SFTP, FTP, WebDAV and S3 servers
- Three language modes and two per-language funny sliders, wired to real copy
- Git-backed append-only version history for settings and sites
